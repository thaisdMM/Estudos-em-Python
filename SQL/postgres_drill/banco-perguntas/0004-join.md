# 7. Liste o nome do membro, o título do livro e a data do empréstimo, só dos empréstimos que ainda estão em aberto (não devolvidos), ordenado pelo nome do membro.

# 8. Qual foi o empréstimo mais recente de um livro de um autor da Itália (authors.country)? Mostre o nome do membro, o título do livro e a data do empréstimo.

```sql
SELECT members.full_name, books.title, loans.loaned_on
FROM members
INNER JOIN loans ON members.id = loans.member_id
INNER JOIN books ON books.id = loans.book_id
INNER JOIN authors ON authors.id = books.author_id
WHERE authors.country = 'Italy'
ORDER BY loans.loaned_on DESC
LIMIT 1;
```

```
-------------+------------------+------------

(1 row)
```
